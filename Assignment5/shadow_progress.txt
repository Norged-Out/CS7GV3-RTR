shadow progress

1. what ShadowMap.* does

The ShadowMap class is the manager for my whole shadow setup.

At first it only handled normal depth shadow maps.
Now it can handle both:
- normal depth shadow maps
- MSM moment shadow maps

So right now it:
- creates the shadow framebuffer
- creates either the depth texture or the moment texture
- sets up the light-space matrix for the directional light
- begins and ends the shadow pass
- lets the scene shader sample the correct shadow texture later


2. what the shaders do

shadow.vert:
- sends geometry into light space during the shadow pass

shadow.frag:
- in normal depth mode, it basically lets the usual shadow depth happen
- in MSM mode, it writes 4 depth moments:
  z, z^2, z^3, z^4

scene.vert:
- sends world position, normal, UVs, tangent basis, and light-space position to the fragment shader

scene.frag:
- does the actual lighting
- samples textures
- handles optional normal mapping
- now supports 3 shadow paths:
  - hard depth shadows
  - PCF depth shadows
  - MSM shadows


3. how I did baseline shadow maps

For the baseline version, I render the scene twice.

First pass:
- render from the light's point of view
- store only depth in the shadow map

Second pass:
- render the scene normally from the camera
- convert each fragment into light space
- compare its depth against the depth stored in the shadow map

If the fragment is farther than the stored depth, it is in shadow.
If not, it is lit.

That is my hard-shadow baseline.


4. how I did PCF shadow maps

After the baseline worked, I added PCF.

Instead of checking the shadow map once, I sample a small 3x3 area around the current shadow-map coordinate.
Then I average those results.

So:
- hard shadows = one compare
- PCF shadows = a bunch of nearby compares averaged together

This makes the edges softer and less jagged.

Big thing I learned:
- PCF helps soften edges
- PCF does not really fix shadow acne
- bias handling is what matters more for that


5. how I did MSM

For MSM, I changed the shadow system so it can store 4 depth moments instead of just one depth value.

In the MSM shadow pass:
- I store:
  - z
  - z^2
  - z^3
  - z^4
- then I run a simple Gaussian blur over the moment texture

Then in the lighting pass:
- I sample those 4 values
- run the MSM reconstruction math
- get back a shadow intensity

So instead of asking:
- "am I behind one stored depth value?"

MSM is more like:
- "based on these 4 stored depth statistics, how shadowed should I be?"


6. what I fixed to make MSM usable

The first MSM version worked, but it still had visible acne / weirdness.

So I cleaned up a few important things:
- made sure MSM uses the real fragment depth when writing moments
- kept the paper's small moment bias for stability
- added a small practical receiver bias for MSM too
- clamped the final shadow value
- made sure the moment texture uses filtering

After that, the acne basically went away and MSM started looking much more believable.


7. what the three modes look like now

Hard:
- sharp shadow edge

PCF:
- blurry / softened edge from averaging nearby samples

MSM:
- still solid and dark where it should be
- but the transition feels smoother and more natural

For the final demo, I cleaned the UI up instead of keeping every MSM experiment as a toggle.
Later on, I expanded the UI again because the report needed more controlled comparisons.

So right now the shadow UI can also show:
- baseline bias presets and sliders
- PCF radius
- shadow-map resolution
- raw / legacy / current MSM presets
- signed depth on/off
- improved bias target on/off
- blur on/off plus blur scale
- live metrics like FPS, frame time, shadow pass time, blur time, and estimated shadow memory

This makes the project less like a fixed demo and more like a little shadow-comparison lab.


8. the actual order I did this in

This part matters because the final result was not just "I added MSM and it worked".

The order was more like this:

1. I first got normal hard shadow mapping working.
- It worked as a baseline, but it had acne / self-shadowing.

2. Then I added PCF.
- That made the shadow edge softer.
- But PCF did not really fix the acne.

3. Then I cleaned up the baseline shadow setup.
- I made the renderer use directional lighting properly instead of mixing point-light style shading with directional shadows.
- I also made the baseline bias use the real geometric normal instead of the normal-mapped one.
- That is what made the hard and PCF versions look way cleaner.

4. After that baseline cleanup, I added MSM.
- So MSM was not the first shadow thing I did.
- It was built on top of a cleaner baseline.

5. The first MSM version worked, but still had visible issues.
- It was more like "the pipeline exists" than "the result is polished".

6. Then I improved the MSM version with the minimum practical fixes.
- real fragment depth for moment writing
- paper bias for moment stability
- small MSM receiver bias
- clamped shadow result
- filtered moment texture
- simple Gaussian blur on the moment map

7. After those MSM fixes, the acne pretty much disappeared and MSM started looking like a more proper shadow.

So the actual methodology was:
- hard shadows first
- PCF second
- baseline acne cleanup third
- MSM implementation fourth
- MSM stabilization fifth
